# 아이디어 주차장

떠오르면 여기 한 줄. 버스트 시작할 때 골라 꺼낸다. 출처가 코드 주석이면 파일을 적어둔다.

## 게임플레이 / 이벤트
- 감각은 전부 충돌 볼륨이다 — 시야는 원뿔 충돌, 청각은 구 볼륨, 피부는 접촉 (mvc3d `_concept_eventreceptor.py`)
- Damage는 타입을 갖는다 (pierce는 물리력 없음, blunt는 있음). Heal ≠ -Damage (같은 파일)
- 받는 쪽이 결과를 정하는 방어: 미라는 hp 복원(불사), 올빼미는 speed 복원 (같은 파일)
- 주문 시전을 시리얼라이즈드 입력으로 — "I'm the bone of my sword" 타이핑/음성 캐스팅, 캐릭터 레벨이 아니라 플레이어 숙련이 레벨 (같은 파일)
- 정적 배경(건물)은 로직 없이 충돌 데이터만 시뮬에 등록 — 눈이 지붕에 쌓이는 것은 충돌점의 문제 (같은 파일)
- 키맵 문자열 `'w':'move_up*1'` 동사×배율 파싱 (mvc3d controller.py) — 2층 컨트롤러에 부활시킬 것

## 코어 / 성능
- 함수 타입힌트로 속성 스키마 선언 (`def f(pos:3, vel:3, dt)`) — axis.py의 마법. 명시 등록의 슈가로만 부활 검토
- uid 슬롯 0을 쓰레기통으로: 죽은 uid의 쓰기가 0번 열로 무해하게 빠지게 (bullet_unit.py `test_uidmap`)
- 충돌 페어 결과를 이벤트 큐로 넘길 때 (i,j) int64 2행 배열로
- 고정 크기 모드(UnitArray fixed) — 총알처럼 상한이 명확한 아키타입은 증설 금지로 예측 가능성 확보

## 뷰 / 렌더
- 본 데이터만 전송(6.4KB)하고 스키닝은 뷰에서 — 옷감 정점 600KB 금지 (test_renderer.py 독백)
- draw-type 20종 목록 초안 잡기: point, line, instanced-mesh, sk-mesh, sprite, …
- 정점 페인트로 개성 — 포토리얼 안 함 ("that's not my world", 같은 파일)
- 다중 뷰 동시 접속 (websocket 브로드캐스트는 threeinit에서 검증됨) — 관전자 모드는 공짜
- 라즈베리파이4를 최소 사양 뷰 타깃으로 유지 (instanced snow가 돌았다)
- VR: three.js VRButton 실험 흔적 (mvc3d dd/) — 브라우저 뷰 채택 시 거의 공짜

## 도구
- 리플레이: 입력 이벤트 스트림만 저장하면 결정론적 재생 가능한지 검토 (커널 결정론 전제)
- 배열 상태 스냅샷 저장/로드 (np.save 묶음) — 세이브가 아니라 디버깅용 타임머신
