# Variant: OpenGL 4.6 core (the v1 backend)

Folder `src/axis3d/gpu/gl46/`. Every fact a porter or implementer needs about GL lives here, not in `spec/`. (ADR 0009)

## Context
GLFW hints: `CONTEXT_VERSION_MAJOR 4`, `MINOR 6`, `OPENGL_PROFILE CORE`, `OPENGL_FORWARD_COMPAT True`,
`SRGB_CAPABLE True`, `OPENGL_DEBUG_CONTEXT` when `AXIS3D_DEBUG=1`. Then `glEnable(GL_FRAMEBUFFER_SRGB)`,
`glClipControl(GL_LOWER_LEFT, GL_ZERO_TO_ONE)`, `glEnable(GL_DEPTH_TEST)`, `glDepthFunc(GL_GREATER)`, `glClearDepth(0.0)`.
Shader header written by `preprocess.py`: `#version 460 core`.

## Interface → GL (DSA only; no `glBind*` to edit)
| interface | GL 4.6 calls |
|---|---|
| `create_buffer static` | `glCreateBuffers`, `glNamedBufferStorage(size, data, 0)` |
| `create_buffer stream` | `glNamedBufferStorage(3 × size, None, MAP_WRITE | MAP_PERSISTENT | MAP_COHERENT)`, `glMapNamedBufferRange` once |
| `create_buffer readback` | `glNamedBufferStorage(size, None, MAP_READ | MAP_PERSISTENT)`; `read` waits `glClientWaitSync` |
| `write` | `glNamedBufferSubData` (static, outside the frame loop only) |
| `create_texture` | `glCreateTextures(GL_TEXTURE_2D)`, `glTextureStorage2D`, `glTextureSubImage2D`, `glGenerateTextureMipmap` |
| `create_pipeline` | `glCreateProgram` + shaders; state stored as `PipelineState`, applied in `bind_pipeline` |
| `create_target` | `glCreateFramebuffers`, `glNamedFramebufferTexture`, `glCheckNamedFramebufferStatus` |
| `begin_frame` | `glClientWaitSync` on slot fence, `glDeleteSync`; ring index = tick % 3 |
| `end_frame` | `glFenceSync`, `glfw.swap_buffers` |
| `begin_pass` | `glBindFramebuffer`, `glViewport`, `glClearNamedFramebufferfv` colour / depth |
| `bind_pipeline` | `glUseProgram`; apply depth/cull/blend/topology from `PipelineState` (only when changed) |
| `bind_buffer` | `glBindBufferRange(GL_UNIFORM_BUFFER` slot 0 / `GL_SHADER_STORAGE_BUFFER` 1–7, offset = slice offset) |
| `bind_texture` | `glBindTextureUnit(slot, tex)` |
| `bind_geometry` | one VAO created at device init with `glVertexArrayAttribFormat` for the fixed layout; `glVertexArrayVertexBuffer(vao, 0, vb, 0, 48)`, `glVertexArrayElementBuffer` |
| `draw_indirect` | `glBindBuffer(GL_DRAW_INDIRECT_BUFFER, buf)` then `glMultiDrawElementsIndirect(mode, GL_UNSIGNED_INT, offset, count, stride)` |
| `dispatch` | `glUseProgram`, `glDispatchCompute` |
| `barrier` | `glMemoryBarrier(GL_SHADER_STORAGE_BARRIER_BIT | GL_COMMAND_BARRIER_BIT ...)` |
`DrawCommand` layout matches `DrawElementsIndirectCommand` (count, instanceCount, firstIndex, baseVertex, baseInstance).

## AZDO patterns used
Persistent-mapped triple ring for every stream buffer; one indirect draw per pipeline; one VAO for the whole app;
all per-instance data in SSBOs read with `gl_BaseInstance + gl_InstanceID`; no `glGet*` and no `glFinish` in the loop.

## Debug (`gl46/debug.py`)
`glDebugMessageCallback` prints each message id once; `GL_DEBUG_SEVERITY_NOTIFICATION` filtered; raise on `ERROR`
severity when `AXIS3D_DEBUG=1`. PyOpenGL: `OpenGL.ERROR_CHECKING = False` after startup in release runs.

## Optional extensions (feature-checked at init, never required)
`GL_ARB_bindless_texture` (textures as u64 handles in SSBO), `GL_NV_mesh_shader`, `GL_ARB_gl_spirv`. Absent → the
default path runs; `device.features` is a frozenset of the present ones.

## Known traps
- PyOpenGL needs `ctypes.c_void_p(offset)` for pointer-offset arguments; numpy arrays pass directly.
- `glMapNamedBufferRange` returns a ctypes pointer: wrap with `np.ctypeslib.as_array` once, keep the view.
- Persistent + coherent mapping is simplest; without `COHERENT` you must `glFlushMappedNamedBufferRange`.
- `glGetUniformLocation` returns `-1` for optimised-out uniforms (E-005); we have no loose uniforms, so it never runs.
- Creating any GL object before the context exists fails obscurely (E-006); `create_device` asserts a current context.
